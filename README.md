# Everyday Vegas — Image Prep

Browser tool for prepping Everyday.Vegas article images: 1200×675 JPG, size-targeted (≤200 KB / ≤300 KB), Vivid filter preset, 16:9 crop, mosaic face blur, batch export to zip. Runs entirely in the browser — nothing is uploaded.

## Usage

Open the [GitHub Pages link](https://buiniakou.github.io/ev-image-prep/), drop images, adjust, download.
